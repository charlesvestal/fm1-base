FM-1 Companion

Use this page to keep your FM-1's files on this computer: download one, send one back, or back them all up in one zip file and put them back later. You can also change the firmware's settings here. Connect the FM-1 with a USB cable, or open the firmware's emulator in another tab. It works in Chrome and Edge, with nothing to install.

Press Connect to start.

This FM-1

Files

    The FM-1 checks each file it receives and keeps it only when every byte arrived. If a transfer stops partway, send the same file again. The FM-1 refuses changes while it plays: stop it first.
